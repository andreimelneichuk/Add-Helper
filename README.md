# Ad Helper

Сервис, который сам ведёт рекламу малого бизнеса: владелец рассказывает о бизнесе, задаёт бюджет и получает клиентов. Настройка ставок, ключевых фраз и рекламных кабинетов ему не нужна.

**Статус:** проектирование, кода пока нет. Исходная постановка: [Оплачиваемое тестовое задание.md](Оплачиваемое%20тестовое%20задание.md).

Текущие задачи: [index.md](index.md). Правила разработки: [CLAUDE.md](CLAUDE.md).

## Главные решения

1. **Первая площадка: Яндекс Директ, единая перфоманс-кампания через API v501.** VK Реклама подключается вторым адаптером только после прохождения всех сценариев на Директе.
2. **Бюджет защищают несколько независимых слоёв.** Лимиты выставляются на стороне площадки так, чтобы бюджет не был превышен даже при полной остановке нашего сервиса.
3. **Решения принимают детерминированные правила со статистикой.** Языковая модель пишет объявления и понятные объяснения, но не управляет деньгами.
4. **A/B-тесты проводятся собственным механизмом чередования.** Эксперименты Директ Про не найдены в API и рассчитаны на больший объём конверсий, чем у малого бизнеса.
5. **Все изменения проходят через единый журнал.** Он обеспечивает историю, объяснения и откат одним механизмом.
6. **Модульный монолит на Python и PostgreSQL, развёртывание через Docker Compose.** Заказчик должен поднять сервис сам, без DevOps-инженера и без вопросов автору.
