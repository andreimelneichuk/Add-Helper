# Задача 12. ML: Промпт-инжиниринг для генерации фонов (FLUX / Recraft) и доводка извлекателя фактов

- **Приоритет:** P1 (Важно для визуального контента и онбординга)
- **Сложность:** Средняя (Medium)
- **Трудозатраты с Claude Code:** 3–4 часа
- **Зависимости:** Задача 04, Задача 06
- **Блокирует:** Запуск генерации графических объявлений

---

## 1. Что нужно сделать

1. **Мини-шутаут и промпт-инжиниринг визуальных моделей (OpenRouter):**
   - Провести сравнительный прогон моделей **FLUX (FLUX.2 / Dev)** и **Recraft (V3 / V4.1)** на 3 эталонных сценариях малого бизнеса:
     1. Салон красоты: *нюдовый маникюр крупным планом, профессиональный свет, чистая студия*.
     2. Студия йоги: *зал с гамаками для аэройоги, утреннее солнце, панорамные окна*.
     3. Автосервис: *диагностика автомобиля в чистом современном боксе*.
   - Оценить по критериям: фотореализм, отсутствие артефактов на людях/руках, четкость в миниатюре 150×150 px для поиска Яндекса, стоимость генерации (в диапазоне $0.015–$0.035).
   - Создать LLM-генератор фото-промптов: перевод ниши и заголовка на естественный английский язык с техническими параметрами съемки (линза, свет, стиль) для максимального качества генерации.

2. **Доводка извлекателя фактов (`Site Extractor`):**
   - Настройка промпта `site-1` для устойчивого извлечения пар «услуга — цена», акций и гео-привязки из сырого HTML / innerText после Playwright.
   - Проверка цитируемости: модель возвращает цитату, а код проверяет точное вхождение в DOM (защита от галлюцинаций в профиле бизнеса).

3. **ML-разборщик команд чата (`Command Parser`):**
   - Доводка промпта `commands-1` для трансляции свободных фраз пользователя («убавь бюджет до 10к и отключи рекламу с педикюром») в закрытый JSON команд (`SET_BUDGET`, `PAUSE_AD`).

---

## 2. Критерии готовности (Definition of Done)

- [ ] Проведен мини-шутаут FLUX vs Recraft на тестовых сценариях, определен основной генератор и резерв (fallback).
- [ ] Промпт-генератор стабильно формирует качественные коммерческие запросы для Директа.
- [ ] Извлекатель фактов заполняет профиль тестового сайта без галлюцинаций.
- [ ] Разборщик команд безошибочно распознает типовые пользовательские фразы.
