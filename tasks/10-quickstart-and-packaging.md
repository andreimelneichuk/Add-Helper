# Задача 10. Легкое развертывание и скрипт `quickstart.sh` («без вопросов автору»)

- **Приоритет:** P1 (Критерий приёмки)
- **Сложность:** Низкая (Low)
- **Трудозатраты с Claude Code:** 2–3 часа (вместо 1–2 дней у человека)
- **Зависимости:** Задачи 01, 02
- **Блокирует:** Финальная приёмка заказчиком

---

## 1. Проблема
В задании указано: *«Мы самостоятельно развернули сервис по документации без вопросов автору... Мы настроили сервис со своими авторизационными приложениями и подключили свои рекламные кабинеты без изменения кода»*.
Сейчас проект имеет много неявных зависимостей (специфичный порт PostgreSQL 5433, Caddyfile, генерация мастер-ключа шифрования Fernet, строки подключения Procrastinate, переменные окружения).

## 2. Что нужно сделать

1. **Создать интерактивный скрипт быстрой настройки (`scripts/quickstart.sh`):**
   - Проверяет наличие Docker, Docker Compose, портов.
   - Если `.env` отсутствует, создает его, автоматически генерирует криптографически стойкие ключи `POSTGRES_PASSWORD` и `TOKEN_ENCRYPTION_KEYS`.
   - Запрашивает у заказчика Client ID и Secret Яндекс ID и API-ключ модели (или предлагает запустить без LLM на шаблонах).
   - Запускает контейнеры `docker compose up -d` и ждет успешного прохождения миграций Alembic.
   - Проверяет доступность сервиса вызовом `adhelper check` внутри контейнера.
2. **Проверить документацию развертывания (`docs/08-deployment.md`):**
   - Убедиться, что чистая установка на пустом сервере Ubuntu 22.04 / 24.04 поднимается ровно за 3 команды:
     ```bash
     git clone <repo>
     cd <repo>
     ./scripts/quickstart.sh
     ```
3. **Smoke-тест на чистой машине:**
   - Прогнать сценарий поднятия на виртуальной машине без предустановленных локальных настроек разработчика.

## 3. Критерии готовности (Definition of Done)
- [ ] Скрипт `scripts/quickstart.sh` выполняет всю первичную настройку.
- [ ] Сервис поднимается «из коробки» без правок в кодовой базе.
- [ ] Команда `docker compose exec app adhelper check` возвращает 0 (все проверки зеленые).
