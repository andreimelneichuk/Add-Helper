## Пять приоритетов, из которых вытекает всё остальное

Приоритеты при конфликте требований, от главного к второстепенному:

1. **Деньги.** Расход не превышает бюджет клиента.
2. **Точность.** Действия и статистика сервиса соответствуют тому, что на самом деле в Директе.
3. **Восстановимость.** Любой сбой не ведёт к двойному выполнению действия и к потере истории.
4. **Понятность.** Владелец понимает, что происходит.
5. **Простота развёртывания.** Заказчик поднимает сервис сам, без отдельного инженера по эксплуатации.

Сервис ведёт рекламу на реальные деньги малого бизнеса, поэтому каждое решение в документах сверено с этим списком. Когда оптимизация конфликтует с контролем бюджета, выигрывает контроль.
