# Развёртывание и настройка

> **Черновик.** Кода пока нет, поэтому команды и переменные описывают проектное решение и не проверены запуском. На этапе 7 документ будет доведён до рабочего состояния и проверен чистой установкой.

## 1. Что понадобится

| Что | Требование |
|---|---|
| Сервер | Linux с Docker и Compose; стартово 2 vCPU, 4 ГБ RAM, 40 ГБ SSD. Размещение в РФ из-за персональных данных |
| Домен | A-запись на сервер, открытые порты 80 и 443 |
| Почта | SMTP для уведомлений |
| Приложение Яндекса | Создаётся по §2 |
| Модели | Ключ выбранного провайдера текста и изображений |
| Файлы | Встроенный MinIO или внешнее S3-совместимое хранилище |

## 2. Приложение Яндекса

Приложение заказчика настраивается один раз и используется всеми его пользователями.

1. Создать кампанию в [Директ Про](https://direct.yandex.ru/) на аккаунте разработчика: без неё недоступны настройки API.
2. На [oauth.yandex.ru/client/new](https://oauth.yandex.ru/client/new) создать приложение:
   - Платформа: веб-сервисы.
   - Redirect URI: `https://ВАШ_ДОМЕН/api/auth/yandex/callback`, `https://ВАШ_ДОМЕН/api/accounts/yandex/callback`.
   - Права: `login:info`, `login:email`, `direct:api`, `metrika:read`, `metrika:write`, `passport:business`.
3. Сохранить ClientID и Client secret.
4. В Директе на вкладке «Настройки API» → «Мои заявки» подать заявку на **полный доступ**. Подробно описать приложение, указать актуальную почту. Рассмотрение занимает от часа до трёх рабочих дней, в пик до семи.
5. Проверить в настройках API, что доступ именно полный. Ошибка 58 при одобренной заявке обычно означает тестовый доступ.

Готовый текст заявки будет добавлен сюда после одобрения первой заявки.

## 4. Установка

```bash
git clone <адрес репозитория> ad-helper
```

```bash
cd ad-helper
```

```bash
cp .env.example .env
```

Заполните `.env`:

| Переменная | Назначение |
|---|---|
| `PUBLIC_BASE_URL` | Адрес сервиса, например `https://ads.example.ru` |
| `SECRET_KEY` | Подпись сессий |
| `TOKEN_ENCRYPTION_KEYS` | Ключи шифрования токенов и реквизитов; **потеря делает их нечитаемыми** |
| `POSTGRES_PASSWORD` | Пароль базы |
| `YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET` | Приложение Яндекса |
| `VK_ENABLED`, `VK_CLIENT_ID`, `VK_CLIENT_SECRET` | VK Реклама |
| `TEXT_MODEL_PROVIDER`, `TEXT_MODEL_API_KEY` | Текстовая модель |
| `IMAGE_MODEL_PROVIDER`, `IMAGE_MODEL_API_KEY` | Изображения |
| `S3_ENDPOINT`, `S3_BUCKET`, `S3_ACCESS_KEY`, `S3_SECRET_KEY` | Файлы |
| `SMTP_URL`, `MAIL_FROM` | Почта |
| `RULES_VERSION` | Версия правил автопилота |

Запуск:

```bash
docker compose up -d
```

```bash
docker compose exec app adhelper check
```

Команда `check` проверит настройки, базу, файлы, почту, срок сертификата и параметры приложения Яндекса. Миграции выполняются автоматически при запуске.

## 5. Проверка после установки

1. Откройте адрес сервиса и войдите через Яндекс.
2. Подключите кабинет с правами.
3. Откройте служебную панель: все проверки зелёные.
4. Пройдите мастер настройки и создайте кампанию с маленьким бюджетом.
5. Сравните созданные объекты с кабинетом.

## 6. Эксплуатация

| Задача | Как |
|---|---|
| Обновление | `git pull`, затем `docker compose up -d --build`; миграции обратно совместимы в пределах версии |
| Резервные копии | Ежедневная `pg_dump` на внешнее хранилище, файлы и ключи отдельно |
| Восстановление | Описано пошагово, проверяется до сдачи |
| Логи | `docker compose logs`, токены маскированы |
| Мониторинг | `/healthz`, служебная панель, письма о сбоях администратору |
| Смена ключей шифрования | Новый ключ добавляется в начало `TOKEN_ENCRYPTION_KEYS`, запускается команда перешифровки |

**Аварийная остановка рекламы:** `adhelper emergency-stop --business <id>` или кнопка в служебной панели. Даже когда сервис выключен, лимиты периода продолжают действовать на стороне площадки.

## 7. Юридический минимум для эксплуатации

Заказчик как оператор данных самостоятельно:
- публикует политику обработки персональных данных и получает согласия;
- уведомляет Роскомнадзор, если это требуется;
- хранит данные на серверах в РФ;
- проверяет условия использования выбранных моделей.

Шаблоны текстов не заменяют консультации юриста.

## 8. Частые проблемы

Раздел будет заполнен по итогам чистой установки: `58`, `redirect_uri mismatch`, нет баллов, код статистики не найден, сертификат не выпускается.
